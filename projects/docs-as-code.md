# CI/CD для документации

Я перевела инженерную документацию на рельсы **Docs-as-Code** и полностью автоматизировала рутинные проверки. Теперь ни один Pull Request не попадает в основную ветку, пока его не проверит автотестовый пайплайн в GitHub Actions.

Настроила поэтапную валидацию каждого коммита, чтобы авторы сфокусировались на смысле, а не на синтаксисе.

В итоге я сократила время ревью документации на 40% и полностью исключила попадание невалидных ссылок и стилистических ошибок на продуктовый контур.
